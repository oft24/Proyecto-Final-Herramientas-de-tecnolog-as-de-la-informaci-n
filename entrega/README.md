# Entrega en la plataforma

El archivo versionado `Evidencias_EntregaFinal_en_progreso.docx` es un **borrador histórico**, no la versión final para subir. Se conserva para no perder el trabajo previo. `actualizar_borrador.py` también pertenece a esa preparación inicial; no ejecutarlo sobre el Word actualizado del alumno.

La plantilla actualizada se conserva en el equipo del alumno y sus ocho capturas se publican en [docs/capturas](../docs/capturas/README.md). Antes de subir el Word, reemplazar la nota de SMTP pendiente por el resultado real de [correo_confirmacion.md](../docs/correo_confirmacion.md), revisar capturas y confirmar el enlace al repositorio.

El Word se entrega en la plataforma. El código, las corridas y la documentación técnica se revisan desde GitHub mediante [el índice](../docs/ENTREGA_FINAL.md). La presentación en vivo y su video de respaldo son el siguiente trabajo, no se declaran realizados.
